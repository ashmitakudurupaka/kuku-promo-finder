1. Problem Choice & Strategic Framing

Why Problem 1? In vertical microdramas (Kuku, ReelShort, DramaBox), User Acquisition (CAC) and TikTok ad creative fatigue are the company's highest cost and growth bottlenecks. Editors spend 15–20 hours per show manually watching 50+ episodes to find 30-second clips. Solving promo extraction from screenplays automates ad discovery, scaling UA volume 100x while saving thousands of editor hours.

Core Scoping & Architectural Assumptions:

  • Beat IDs Only (Zero Timestamp Hallucination): Models only pick immutable beat IDs (`ep01_b014`). Code looks up exact millisecond timecodes.
  • Deterministic Duration & Dead Air: Enforces 20–60s bounds; trims dead air before hooks so the hook lands in seconds 0–3. Dropped picks are logged in rejected.json.
  • Cold Viewer Zero-Context Test: A second model call sees ONLY clip text (zero show bible) to test standalone comprehension directly.
2. Pipeline Architecture: Code vs. AI Division of Labor

What We Kept as Code (Deterministic Rules):

  • Tolerant Screenplay AST Parser: Parses scene headers, character deliveries, action lines, and millisecond timecodes (`src/parser.py`).
  • Show Bible Extraction: Pass over 50 episodes extracts characters, relationships, and 5 major arcs, enabling cross-episode promos (`src/show_bible.py`).
  • Temporal NMS & Dead-Air Trimmer: Trims pre-hook pauses and suppresses overlapping cuts with IoU threshold 0.35.

What We Gave to AI & Swappable Model (.env):

  • Candidate Proposer: Proposes candidate beat ID spans using show context and trope markers.
  • Cold-Viewer Blind Judge: Reads only clip text to rate who-is-who clarity (1-5), stop rate (1-5), and cliffhanger urgency (1-5).
  • Swappable Interface: Plugs into any OpenAI-compatible API via `.env` (Groq, Gemini, OpenRouter, Ollama) and includes zero-key local fallback.
3. Production Scale, Speed & Unit Economics

Real-World Show Volume: Kuku releases multiple shows weekly. Our two-stage pipeline scans 50 episodes in 6.05 seconds on standard CPU hardware. Token footprint is minimal (~1,200 tokens/episode) because candidate pre-filtering prunes dead air before LLM evaluation.

Unit Economics: Compute cost is under $0.008 per 50-episode show. Processing 500 episodes/month (weekly shows) costs under $0.10 total—yielding a 99.9% cost reduction compared to human editor log-and-clip workflows while delivering instant campaign packs.

Human-in-the-Loop Story:
Editors review candidates in `app.py`, clicking Accept/Reject. Decisions log to `decisions.json` to feed back as few-shot examples for future runs.

5. Quality Checking: Where Does Our Tool Pick Badly? (Honest Failure Audit)

Operating strictly on screenplay text allows zero-rendering speed, but creates blind spots where text heuristics diverge from final video reality. Our automated Quality Audit Engine explicitly detects and flags four failure modes:

Failure Mode 1: The 'Visual-Only Dead Air' Trap
Issue: High action text (e.g. "Juliana stares in terror, her knuckles white") scored highly for drama, but has zero dialogue for 8s. On TikTok/Reels, silent scenes without voiceover suffer 60%+ drop-off.
Real Case: Episode 6 opening woodland trek (`00:00 - 00:28`). Atmospheric in script, sluggish on feed.
Fix & Rule: Enforced dialogue density threshold (>0.8 words/sec). Auto-flags with `FAIL_SILENT_VISUAL` for human review.
Failure Mode 2: The 'Serialized Lore' Trap
Issue: Tense dialogue referencing obscure off-screen names (e.g. "Father Thomas delivered Lord Sterling's letters!") sounds high-stakes to fans but confuses cold viewers.
Real Case: Episode 48 council negotiation (`00:15 - 00:52`).
Fix & Rule: Cold-Viewer Judge penalizes non-archetypal proper nouns; tagged for Retargeting only (`WARN_LORE_DEPENDENCY`), never Cold ToFu.
Failure Mode 3: The 'False Cliffhanger' (De-escalation Trap)
Issue: A scene closes with an episode boundary or `Cut to black`, but the conflict resolved 5 seconds earlier with mutual comfort ("We are safe beside the hearth"). Naive punctuation models mislabel this a cliffhanger.
Real Case: Episode 8 ending hearth dialogue.
Fix & Rule: Post-cut tension verifier inspects following lines, rejecting clips where tension resolved immediately (`POST_CUT_TENSION_RESOLVED`).
Failure Mode 4: Mid-Sentence Pacing Truncation
Issue: Hard sliding duration windows (e.g. strict 60.0s) cut mid-word or mid-breath, creating awkward syntactic cuts.
Real Case: Fixed duration cuts across long monologue turns.
Fix & Rule: Strict semantic beat boundary snapping guarantees all cuts end on natural dramatic punctuation pauses (`.`, `!`, `?`, `...`).
